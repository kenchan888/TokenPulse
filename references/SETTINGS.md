# 参数与外观

> 所有参数都是环境变量，在 `start-hud.bat` 顶部放开对应的 `set` 行即可，改完重新双击。
> 单位除注明外都是 **DIP**（逻辑像素），运行时乘以屏幕缩放系数。

---

## 1. 位置

| 变量 | 默认 | 含义 |
|---|---|---|
| `TP_LEFT` | 300 | 左段兜底起点，**仅在侧边栏右缘探测失败时使用** |
| `TP_RIGHT` | 6 | 右段距窗口右边缘 |
| `TP_BOTTOM` | 7.3 | 兜底距窗口底，**仅在量不到提示文案时使用** |

正常情况下三个都不需要设：左段贴着实时探测出的侧边栏右缘 + 7 DIP，竖直方向跟着「内容由 AI 生成…」的墨迹中心走。只有探测连续失败（例如侧边栏折叠、主题大改）才用它们兜底。

## 2. 外观

| 变量 | 默认 | 含义 |
|---|---|---|
| `TP_INK` | 0.70 | 文字不透明度 0~1。0.70 压出来是 `#4C4C4C`，与对话页顶部「共消耗 …」那行同深；0.41 约等于提示文案原色，0.53 偏浅、发虚 |
| `TP_GAMMA` | 0.90 | 抗锯齿 gamma。<1 略加粗、>1 略变细。灰度抗锯齿比 ClearType 细，0.9 是补这个观感 |
| `TP_OPACITY` | 255 | 整条窗口不透明度，夹在 60~255 |

**深浅怎么挑**：先定 `TP_INK`，`TP_GAMMA` 一般不动。想要更淡就调 `TP_OPACITY`（整条一起淡），不要用 `TP_INK` 压到 0.4 以下——那会同时削弱字形边缘，看着像糊了。

## 3. 显示范围

| 变量 | 默认 | 含义 |
|---|---|---|
| `TP_ONLY_CHAT` | 1 | `1` = 只在对话页显示；`0` = 所有页面都显示 |

关掉之后条子会常驻，代价是入口页也挂着一行数字。

## 4. 会话绑定

| 变量 | 默认 | 含义 |
|---|---|---|
| `TP_SESSION` | 空 | 钉死某个会话：会话 uuid 或 jsonl 绝对路径。留空 = 自动跟随界面 |

多窗口并排、各自显示不同对话时，自动跟随分不清"此刻在看哪个"，用这个把某个窗口钉死。

## 5. 运行控制

| 变量 | 含义 |
|---|---|
| `TP_NORELOAD` | 设任意值即关闭热重载。调试时怕它自己重启就设上 |
| `TP_START_DELAY` | 替身启动前的延迟秒数，用于避开上一实例还没放掉的互斥体；一般不用动 |
| `TP_FOLLOW_MS` | 跟随线程在位移期间的最小间隔（毫秒），默认 2 |

**诊断专用**（不要写进 bat，只做临时排查）：

| 变量 | 用途 |
|---|---|
| `TP_MUTEX` | 换互斥体名，跑第二个实例做对照 |
| `TP_CLASS` | 换窗口类名，测试脚本用它隔离 |
| `TP_OWNER_TITLE` | 换要挂靠的窗口标题，测试里自建假 WorkBuddy 窗口时用 |
| `TP_LOG_ROOT` / `TP_DAEMON_LOG` / `TP_RENDERER_LOG` | 换数据源路径，测试用假日志 |
| `TP_LOG` | 换主日志文件路径 |

## 6. 想微调版式时的常量

这些不是环境变量，改 `hud.py` 里的常量，改完 2~3 秒热重载生效：

| 常量 | 值 | 动它会怎样 |
|---|---|---|
| `FONT_DIP` | 13.0 | 两段文字字号。比提示文案（12）大半号是这个产品的基本观感，别乱动 |
| `SIDE_GAP_DIP` | 7.0 | 左段距侧边栏右缘。改大就离侧边栏更远 |
| `GAP_R_DIP` | 6.0 | 右段距窗口右边 |
| `MIN_W_DIP` | 150.0 | 最小宽度，小于它就按档降级 |
| `TODAY_W_DIP` / `TODAY_H_DIP` | 256 / 62 | 今日面板尺寸。改宽要同步看三列锚点是否还对得上 |
| `TODAY_V_DIP` / `TODAY_U_DIP` / `TODAY_L_DIP` | 18 / 11 / 13 | 面板的数字 / 单位 / 标签字号 |
| `TODAY_GAP_VU_DIP` / `TODAY_GAP_VU_CJK_DIP` | 3 / 2.5 | 数字与单位间距（拉丁 / 中文分开） |
| `TODAY_INK_NUM` / `TODAY_INK_LBL` | 255 / 180 | 数字与标签的墨量 |

**改字号后必须重测对齐**：单位是按基线对齐的，字号一动间距关系就变；跑 `python render_panel.py` 直接看墨迹框，或者用 `test_metrics.py` 核锚点与对齐基准。
